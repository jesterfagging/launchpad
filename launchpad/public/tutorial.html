GET STARTED

Your connections, step by step.

Get your own provider credentials, save them in Launchpad, and fund the wallets you want to use. These steps work for the website and Telegram.

01 / Solana

Get a Helius RPC

  1. Open the Helius dashboard ↗ and create an account.
  2. Create an API key and copy its Solana Mainnet HTTPS RPC URL, including the API key at the end.
  3. On web or Telegram, open Account → Connections → Solana and paste that complete URL into Custom RPC URL.
  4. If you use the separate Helius API key field, paste only the key there. Launchpad can build the Helius endpoint from it when Custom RPC URL is empty.

Custom RPC URL takes precedence over the separate Helius key. A key is shown as “Saved” after storage; that alone does not validate it. Helius setup guide ↗

Get a Jupiter API key

  1. Open the Jupiter developer portal ↗ and sign in.
  2. Create or join a team, then generate an API key. Enable the APIs your Launchpad tools use, including Swap and Price, if the portal offers permission selection.
  3. Copy the key into Jupiter API key in the same Connections menu. Save, then start a fresh run.

Launchpad uses Jupiter for supported routing and pricing. Provider quotas and plans belong to your provider account. Jupiter setup guide ↗

Choose a stream

Standard RPC logs works with an ordinary Solana RPC WebSocket endpoint. You can leave the custom WebSocket field empty to use Launchpad’s derived endpoint, or enter the WebSocket URL supplied by your RPC provider.

Helius full transaction stream / LaserStream is optional and requires the appropriate Helius access and WebSocket endpoint. Choose it only when your Helius account supports that service. An ordinary RPC subscription does not automatically include it.

Helius streaming documentation ↗

Priority fee, Jito tip and Helius Sender tip are separate from API credentials. Enter the values you want for each run; minimums depend on the selected send path.

02 / Robinhood Chain

  1. Open the Alchemy dashboard ↗, create an account, and create an app for Robinhood Chain Mainnet.
  2. Copy its complete HTTPS RPC URL, including its API key. On web or Telegram, paste it into Account → Connections → Robinhood → Robinhood RPC URL.
  3. Check that the provider’s network is Robinhood Mainnet, chain ID 4663. An Ethereum mainnet or Robinhood testnet endpoint will not work.

You can also use a Robinhood mainnet endpoint from another provider listed in the official connection guide ↗. Public endpoints are rate limited; use your own provider endpoint for regular automated runs.

Robinhood routing uses the chain’s contracts directly. Helius, Jupiter and Jito credentials are for Solana and are not required for Robinhood.

One budget, in ETH

Fund your selected trading wallets with ETH on Robinhood Chain. Copy, Sniping, Market Making and Liquidity all accept ETH amounts or budgets. Launchpad finds the pool and handles asset conversions automatically. Keep extra ETH for gas and applicable management fees. There is no need to buy the pool’s quote token first.

Enter a token contract from the official contract directory ↗ or your chosen market. Review the budget and fees, then Start. Existing quote-token budgets need a new ETH amount after upgrading. Manual LP fee claims return earned pool assets; LP withdrawals return available proceeds to ETH.

03 / Wallets & your first run

  1. Create a Launchpad username and password. Choose your chain and tool.
  2. Open Wallets. Use the default wallet, generate more, or import your own. Copy/Sniping share a 25-wallet cap; LP supports 10 wallets; Market Making supports 5.
  3. Fund the selected trading wallets on the selected chain. The Main cashback wallet in Account is separate and is not automatically used for trades.
  4. Enter your target addresses, developer addresses or token/pool, then set a per-wallet amount or budget. Review the sell settings, fees and gas reserve.
  5. Save the settings, then press Start. Check Activity for a successful connection and confirmed transactions. Stop prevents new submissions; already-broadcast transactions still need reconciliation.

Wallet keys are encrypted and stored on Launchpad’s server for automated signing. Keep a private backup of generated wallets using the account’s verified export flow. Keep private keys, API keys, full setup exports and RPC URLs containing keys out of group chats and screenshots.

Telegram users need their own provider credentials, not a BotFather token. A BotFather token is only used to operate the Telegram bot itself.

04 / Fix a connection error

HTTP 401 / 403
The provider rejected the connection. Confirm the key is current, the URL is complete, and the account has access to the selected service. A Custom RPC URL overrides a separately saved Helius key. If the provider restricts IP addresses, allow the Launchpad server’s outbound IP; requests come from that server. Stop the tool, update its saved connection, then start again.
HTTP 429
The provider’s request or credit limit was reached. Check its dashboard and lower requests per second, reduce simultaneous runs, or choose a suitable provider plan.
Connection timeout
Check the URL, provider status and network selection. Use an HTTPS RPC URL in the RPC field and a WebSocket URL in the stream field.
Insufficient funds / no route
Check the selected trading wallet, chain and token address. On Robinhood, fund the wallet with ETH. Leave gas and fee reserves beyond the trade budget. A pool must have executable liquidity; a ticker match alone does not establish a route.

Charts, swaps and holders

The trading viewer uses DEX Screener for token prices, liquidity, volume, price changes and its embedded chart. The custom live-swaps table reads confirmed transactions from your saved chain RPC. No CoinGecko or DEX Screener API key is needed. Paste a token contract on the correct chain and choose an indexed pool.

The chart shows the pool’s base token. If you search for its quote asset, the chart label explains the difference. Market cap and fully diluted value are shown separately when available. Pool selection changes what you view; Launchpad trades still use your saved routing. Your orders shows Launchpad’s recorded execution activity.

  1. For Robinhood holders, open Account → Connections → Market data and save your Blockscout Pro API key. The free tier uses keys starting with proapi_.
  2. For Solana holders, save your RPC or Helius key under Connections → Solana.
  3. Choose a refresh interval for Launchpad’s statistics and holder snapshots. The DEX Screener chart refreshes independently. Live swaps request updates every second while visible and back off when providers are busy.

New pools may take time to be indexed. If an embedded chart is blocked by your browser or network, use DEX Screener ↗ to open the same pair directly. Solana holders groups the largest 20 token accounts by owner; these are not complete wallet balances or a complete holder count. Load activity for recent buys, sells and weighted entry/exit; Solana history requires Helius. Missing historical USD and profit/loss remain unavailable. Live USD totals and FDV use the current quote-token USD reference; the feed may omit swaps on unsupported pools or during heavy activity. Provider data can lag confirmed transactions.
